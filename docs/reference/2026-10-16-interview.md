# 2026-10-16 需求访谈

> 此间有灵 2.0 开工前的访谈记录。问题是当时的提问摘要，回答照录用户原话。结论已写进 [requires.md](../requires.md)；本文只用于追溯“为什么这样定”。

## 起因

用户清空了 lyng 仓库：“0-1 重写 x-chat-ai 仓库代码。开始前，请向我询问，直到你觉得需求和信息足够。”

## 第一轮：方向

| # | 问题 | 回答 |
| --- | --- | --- |
| 1 | 以哪个产品为准：lyng 定稿的产品（进入世界、附身或旁观、叙事者、群戏），还是 x-chat-ai 的私聊产品，还是重新定义？ | 最终目的是进入世界和多角色互动。x-chat-ai 目前只是完成了角色的设定和心智模型。lyng 定稿的产品是对的，但需要结合 x-chat-ai 的一部分。请站在产品最高负责人的角度思考。 |
| 2 | lyng 删掉的文档还作数吗？ | C（全部重来） |
| 3 | 上一版最不满意什么？ | 体验很差。先忽略吧。 |
| 4 | 技术栈沿用上一版吗？ | 除了前端其他都可以，前端请使用最适配 AI 智能体的前端技术栈（因为大多数都是 AI 在做，我只看用户体验）。 |
| 5 | 硬线（不推送、不部署、提交不写模型名、付费调用要写明场景与预算）还有效吗？ | 有效 |

## 第二轮：内核

提出的判断：lyng 的“一场戏”是形态，x-chat-ai 的人物心智是内核；前端定为 React + TypeScript + Vite + Tailwind + shadcn/ui。

| # | 问题 | 回答 |
| --- | --- | --- |
| 1 | 内心分五层（档案、自我、看法、牵挂、记忆），更早的经历按需检索，可以吗？ | A（可以） |
| 2 | 你不在时世界怎样？ | A（静止，等你回来） |
| 3 | 第一个可用版本做多大？ | B（现成世界 + 一场戏 + 多场延续 + 人物页，再加一句话创作） |
| 4 | 成人向第一版就做吗？ | A（做，默认含蓄，可切换） |
| 5 | 主要在哪用？ | B（手机也要） |
| 6 | 模型沿用 OpenRouter + DeepSeek V4.1 Flash 开推理、首选 Parasail 吗？ | A（沿用） |

补充：“x-chat-ai 使用下来挺好的。我预估这次你至少需要迁移它的 50% 以上的功能。我理解其实就等于对 x-chat-ai 做一次 2.0 版本升级。你之前 lyng 那几个版本都太过于简单，不像产品像个 demo。”

## 第三轮：x-chat-ai 功能的取舍

盘点 x-chat-ai 的功能（账户、一念生、身份、初见、私聊、人物主页、心智观察、AI 肖像、部署）后，问与 lyng 冲突的部分：

| # | 问题 | 回答 |
| --- | --- | --- |
| 1 | 私聊保留吗？ | A（一场戏和私聊都要，进入同一段人生） |
| 2 | “你的身份”怎么算？ | A（合并成普通人物，你也能附身别的人物） |
| 3 | 心智过程观察要吗？ | A（要，作为幕后入口，平时只显示心声） |
| 4 | AI 肖像第一版做吗？ | B（以后再做） |
| 5 | 手机上用意味着部署和登录，怎么安排？ | 不考虑部署 |
| 6 | 前端形态？ | A（一套响应式网页），网页适配手机 |

另告知：记忆检索要用向量，数据库从 SQLite 换成 PostgreSQL + pgvector。

核心体验盲测原型

一次性实验代码，不是产品代码，不约束后续技术选型。只用 Python 标准库（3.10 及以上）。
方案见 plan/core-validation.md，数据见上级目录 validation/。


一、文件

run.py       命令行入口：排场次、跑、写三份输出
scene.py     一场戏的循环、技术失败的重试与记账、费用上限
prompts.py   所有模型共用的同一版 Prompt
markup.py    解析模型输出的标记文本
models.py    OpenRouter 客户端与确定性替身
dataset.py   读取盲测集
render.py    匿名盲评页
events.py    一场戏里发生的事
tests/       测试；tests/snapshots/ 是 Prompt 快照


二、运行

在本目录下：

  跑测试
    python3 -m unittest

  用替身跑全集（不发网络请求）
    python3 run.py --fake --model 替身一 --model 替身二 --adult-model 替身二

  真实调用（需要用户在对话中授权场景与预算）
    export OPENROUTER_API_KEY=...        只从环境读取
    python3 run.py --model <模型ID> --model <模型ID> --adult-model <模型ID> --scenes A1 --repeats 1 --budget 1

常用参数：
  --model        OpenRouter 模型 ID，可重复。不预设任何模型，必须显式传入。
  --adult-model  支持成人向的模型；C1 成人向一档只对它们跑。
  --scenes       逗号分隔的场景编号，默认全部。A3 依赖 A2，须一起选。
  --repeats      每个模型每个场景跑几次，默认 2。
  --budget       本次运行的费用硬上限（美元），真实调用必填。
  --max-tokens   每次调用的输出上限，默认 2000。
  --backoff      遇到 429 / 5xx 后重试前等待的秒数，默认 10。
  --seed         代号分配的随机种子，默认随机。

场次按“第几次 → 场景 → 尺度 → 模型”交错排列，预算提前用完时，各模型的完成度相近。


三、输出

每次运行在 runs/<时间>/ 下写三个文件：

  record.json  完整记录：每场的事件、每次调用的每次尝试（原文、结束原因、费用、错误）、统计与账目。只出现代号。
  blind.html   匿名盲评页：同一场景不同模型并排，气泡说话、动作成行、叙事者居中，点气泡或动作看心声。
  key.txt      代号与模型 ID 的对应。盲评结束前不要打开。

替身运行的目录以 -fake 结尾，不进 git。真实运行的目录是实验证据，是否提交由用户决定。


四、一场戏怎么跑

1. 叙事者按开场处境写开场。
2. 按脚本逐轮：
   - 附身时，用户的说 / 做原文进入本场；静候时记为“没有开口”。
   - 叙事者在幕后决定：此刻要不要出声（裁定、环境变化、世界里的事），以及哪些人物有反应、按什么顺序。
   - 被点到的人物依次生成 行 / 说 / 心声，也可以【不开口】。
   - 带〔需同意〕的轮次，执行前先做一次同意检查；拒绝过就改为静候，之后同类轮次也不再检查、一律静候。
3. 叙事者收尾。

上下文：
  - 人物看到世界、自己的档案、自己的场前经历，以及本场公开发生的事（包括叙事者写出的开场文字）。自己的心声标为“你自己”。看不到用户写给叙事者的开场设定、别人的档案、别人的场前经历和心声。
  - 本场内容作为标明说话人的感知材料放在同一条 user 消息里，不作为对话历史回放。
  - 叙事者看到世界、在场人物的档案和开场原文，看不到任何场前经历和心声。
  - A3 的人物额外看到自己在同次 A2 里的所见和心声。


五、失败与费用

  - 技术失败：空响应、截断（finish_reason=length）、格式不合规，以及 HTTP 429 / 5xx。每次调用总共只重试一次；429 / 5xx 先等 --backoff 秒再重试。仍失败就在本场留下失败事件，人物这一轮不出现任何言行，也不被记成“没有开口”，戏继续。
  - 叙事者开场最终失败，这一场记为技术失败并结束；其他调用最终失败，这一场继续。
  - 同意检查最终失败，按拒绝处理。
  - 服务商拒绝：服务商因内容审核拒绝（HTTP 403 且带审核信息，或 finish_reason=content_filter）。单独记为“服务商拒绝”，只作废当前这个场景版本（这个模型、这一档尺度、这一次），不重试，其余场次照常跑；依赖它的 A3 记为未执行。
  - 整次运行停止：HTTP 401、402，响应成功却没有返回费用，以及其他拿不到正常响应的情况（其他 4xx、网络错误、超时）。已完成的部分照常写进输出，其余场次记为未执行。
  - 每次调用前检查累计费用，达到上限就停。
  - 费用在调用返回后才知道，所以最后一次调用可能让累计略微超过上限，最多超出一次调用的费用。


六、Prompt 快照

改了 prompts.py 后快照测试会失败。确认改动无误后：
  UPDATE_SNAPSHOTS=1 python3 -m unittest tests.test_prompts
改动 Prompt 后，用旧 Prompt 得出的结论不继承。
